#  Opportunity Tracker

A unified platform to discover, save, and manage opportunities for students and young job seekers.

Finding opportunities such as hackathons, internships, scholarships, coding competitions, workshops, fellowships, and entry-level jobs can be challenging when information is scattered across multiple websites and platforms.

**Opportunity Tracker** aims to simplify this process by bringing opportunity discovery and application management together in one place.

## ✨ Key Features

- **📊 Dashboard:** Get an overview of saved opportunities, application progress, completed opportunities, and upcoming deadlines.
- **🔎 Discover Opportunities:** Browse, search, filter, sort, and explore different opportunities.
- **📌 My Opportunities:** Save, manually add, edit, and delete opportunities while tracking their application status.
- **🔔 Notifications:** Monitor upcoming deadlines, overdue applications, and pending updates.
- **⚙️ Settings:** Manage profile preferences and application data.
- **💾 Local Persistence:** Keep application data available using browser LocalStorage.

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Smrithi-krishna/opportunity-tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd opportunity-tracker
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to access the application.
